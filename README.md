# AWS Linux Web Server Deployment

A hands-on AWS project focused on deploying and configuring a Linux-based Nginx web server using Amazon EC2.

## Technologies

- AWS EC2
- AWS VPC
- AWS Security Groups
- Linux
- Nginx
- SSH

## Project Overview

This project demonstrates the deployment of a Linux web server on Amazon EC2 and the configuration of basic AWS networking and security required to access the server remotely.

## Planned Implementation

- Launch a Linux-based EC2 instance
- Configure network and security settings
- Connect to the EC2 instance using SSH
- Install and configure Nginx
- Host a simple web page
- Test HTTP access from a web browser

## Architecture

Laptop → SSH → EC2 → Linux → Nginx → Web Browser
